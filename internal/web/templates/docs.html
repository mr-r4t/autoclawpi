Endpoints

GET /v1/models

List available models. Requires API key too if configured in Settings (same Bearer header).

curl -H "Authorization: Bearer sk-your-key-here" http://localhost:8787/v1/models
POST /v1/chat/completions

Send a chat completion request. OpenAI-compatible format.

curl -X POST http://localhost:8787/v1/chat/completions \
  -H "Authorization: Bearer sk-your-key-here" \
  -H "Content-Type: application/json" \
  -d '{"model":"glm-5.3-flash","messages":[{"role":"user","content":"halo"}]}'

Response

Non-streaming response follows the OpenAI format, including token usage:

{ "id": "chatcmpl-...", "object": "chat.completion", "model": "zai_glm-5.3-flash", "choices": [{ "index": 0, "finish_reason": "stop", "message": { "role": "assistant", "content": "Halo! Ada yang bisa saya bantu?" } }], "usage": { "prompt_tokens": 18, "completion_tokens": 60, "total_tokens": 78 } }

Streaming

Set "stream": true to receive Server-Sent Events. Each chunk is an OpenAI chat.completion.chunk; the stream ends with data: [DONE]:

data: {"choices":[{"delta":{"content":"Halo"}}]} data: {"choices":[{"delta":{"content":"!"}}]} data: [DONE]

Parameters

Parameter Type Description
model required string Model ID (e.g., glm-5.3, glm-5.3-flash, deepseek-v4-pro)
messages required array Chat messages [{role, content}] — role: system / user / assistant
stream bool Enable SSE streaming (default: false)
max_tokens int Maximum tokens in response (passed through to the model)

Rate Limit

Requests are limited to 1 request per 1.5 seconds (burst up to 3). Exceeding it returns 429 Too Many Requests — add a delay or retry with backoff on the client side.

Authentication

If an API key is configured in Settings, include it as a header on every endpoint:

Authorization: Bearer sk-your-key-here

Errors & Failover

Errors follow the OpenAI format. When one account fails (e.g. quota used up), autoclawpi automatically retries with the next account in the pool:

{"error":{"message":"...","type":"..."}}
Status Meaning
401 Invalid local API key (check Settings)
429 Local rate limit exceeded (1 req / 1.5s)
503 all_accounts_failed All accounts tried and failed (quota/token issues — check Request Logs for per-account reasons)
